#Sample Student Data Analysis

##Description
This is a beginner Python project that analyzes sample student scores. It calculates the total, average, highest, and lowest scores.

##Technologies Used
Python
Git
GitHub
Visual Studio Code

##Features
Stores student scores in a list
Calculates the total score
Calculates the average score
Finds the highest and lowest scores

##How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:
     
    python sample_data.py
